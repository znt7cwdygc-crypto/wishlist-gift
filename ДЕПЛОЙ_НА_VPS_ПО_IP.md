## Важно: токен бота и приём Stars

В `.env` на сервере должны быть заданы:

- **BOT_TOKEN** — токен бота от @BotFather (тот же бот, из которого открывается Mini App).
- **APP_URL** — адрес, по которому доступно приложение, **без слэша в конце**, например: `http://185.125.219.107:3000`.

При старте сервер **сам вызывает setWebhook** и вешает webhook на `APP_URL/api/payments/telegram-webhook`. Так Telegram будет присылать туда `pre_checkout_query` и `successful_payment`, и приём Stars из веб-приложения будет работать.

Что сделать:

1. Создайте бота в @BotFather (если ещё нет).
2. На сервере: `nano /opt/wishlist-gift-v2/.env` → задайте `BOT_TOKEN=...` и `APP_URL=http://185.125.219.107:3000`.
3. Перезапуск: `pm2 restart wishlist-api`.
4. В логах должно появиться: `✅ Telegram webhook set: http://185.125.219.107:3000/api/payments/telegram-webhook`.

Проверка: откройте в Telegram бота → меню или ссылку на Mini App `/stars` (например `https://t.me/ВашБот/app` или кнопка меню с URL вашего сервера). Выберите сумму, «Отправить» — в чат придёт счёт, нажмите Pay. После оплаты в БД в таблице `donations` появится запись со статусом `paid`.

```bash
cd /opt/wishlist-gift-v2
pm2 status              # статус процесса

pm2 restart wishlist-api   # перезапуск после правки .env

```

## Добавление домена потом

Когда появится домен (например api.ваш-сайт.ru):

1. Настроить Nginx: проксировать запросы на `http://127.0.0.1:3000`.
2. В `.env` на сервере указать `APP_URL=https://ваш-домен.ru` и при необходимости `CORS_ORIGIN`.
3. Если фронт будет на Vercel — в Vercel в переменной `API_URL` указать `https://api.ваш-домен.ru/api`.

Пока можно пользоваться по IP.
