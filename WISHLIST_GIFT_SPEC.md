# Wishlist Gift — Спецификация проекта

Единый документ по описанию продукта, ролям, функционалу и технике.

---

## 1. Суть

**Wishlist Gift** — Telegram Mini App для получения и отправки подарков через **Telegram Stars**.

- Модели создают вишлисты; дарители выбирают подарки или отправляют Stars.
- Оплата — **только Telegram Stars**, без внешних платёжных систем.

---

## 2. Роли

| Роль | Описание |
|------|----------|
| **Модель** | Ведёт вишлист, настраивает профиль (обложка, аватар, био), получает подарки и донаты Stars |
| **Даритель** | Просматривает вишлист, дарит товары или отправляет Stars |
| **Админ** | Панель управления: статистика, модели, транзакции |

---

## 3. Функционал

### 3.1 Для модели

| Функция | Описание |
|---------|----------|
| **Профиль** | Обложка, аватар, био, тема, публичная ссылка |
| **Вишлист** | Товары с фото, ценой (USD), ссылкой; несколько фото на товар |
| **Редактирование** | Добавление, изменение и удаление товаров |
| **Доступ** | Публичный вишлист или по приглашению (invite / allowlist) |
| **Мультиязычность** | RU / EN |

### 3.2 Для дарителя

| Функция | Описание |
|---------|----------|
| **Просмотр вишлиста** | По ссылке модели (deep link) |
| **Подарок** | Выбор товара → резерв → оплата Stars (Telegram Payments) |
| **Донаты Stars** | Прямая отправка Stars без выбора товара (в чате бота — кнопки 50 / 100 / 250 / 500 / 1000 Stars) |
| **Цены** | В Stars и USD (1 Star ≈ $0.01) |

### 3.3 Для админа

| Функция | Описание |
|---------|----------|
| **Статистика** | По платформе (модели, заказы, донаты) |
| **Список моделей** | Просмотр и управление |
| **Транзакции** | Заказы и донаты Stars |

## 4. Техническое

### 4.1 Авторизация

- **Telegram WebApp** — проверка `initData` через **HMAC-SHA256** (секрет бота).
- Бот и Mini App используют один и тот же секрет для верификации.

### 4.2 Платежи

- **Telegram Stars** (валюта **XTR**).
- Для цифровых товаров: `provider_token: ''` (пустая строка).
- Цепочка: **Webhook** → `/start` с кнопками → `callback_query` → отправка счёта → `pre_checkout_query` → `successful_payment`.

### 4.3 База данных (PostgreSQL)

Основные сущности:

| Таблица / сущность | Назначение |
|--------------------|------------|
| `users` | Пользователи (Telegram ID, роль) |
| `model_profiles` | Профили моделей (обложка, аватар, био, public_slug, privacy) |
| `wishlist_items` | Товары вишлиста (фото, цена USD/Stars, ссылка, статус) |
| `orders` | Заказы (товар, даритель, сумма Stars, статус, telegram_payment_charge_id) |
| `donations` | Донаты Stars (модель, даритель, сумма) |
| `model_balances` | Балансы моделей (опционально) |
| `invite_tokens` | Токены приглашений (приватный вишлист) |
| `wishlist_allowed_users` | Allowlist доступа к вишлисту |

## 5. Основные сценарии

### 5.1 Модель

1. Регистрируется / авторизуется через Mini App (initData).
2. Настраивает профиль: обложка, аватар, био, тема.
3. Добавляет товары в вишлист (фото, цена USD, ссылка).
4. Получает публичную ссылку вида `t.me/bot?start=<public_slug>` и делится ею.

### 5.2 Даритель (подарок)

1. Открывает вишлист по ссылке модели.
2. Выбирает товар → нажимает «Подарить за ⭐ N».
3. Бот создаёт заказ, резервирует позицию, отправляет инвойс (XTR).
4. Даритель оплачивает в Telegram → `pre_checkout_query` → `successful_payment`.
5. Бот помечает заказ как оплаченный, товар — как подаренный.

### 5.3 Даритель (донат Stars)

1. В чате с ботом видит кнопки: **50 / 100 / 250 / 500 / 1000** Stars.
2. Нажимает сумму → бот отправляет инвойс на эту сумму (XTR).
3. Оплата → зачисление доната модели (без привязки к товару).
