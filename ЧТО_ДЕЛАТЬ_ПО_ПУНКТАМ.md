- База данных **wishlist_gift** создана на сервере **185.125.219.107** (PostgreSQL, все таблицы).

## Шаг 1. Залить проект в Git (если ещё не залит)

1. Откройте терминал и перейдите в папку проекта:
   ```bash
   cd /Users/vladislav/wishlist-gift-v2
   ```
2. Если Git ещё не инициализирован:
   ```bash
   git init
   ```
3. Добавьте все файлы и сделайте первый коммит:
   ```bash
   git add .
   git commit -m "Wishlist Gift: фронт + API, готово к Vercel"
   ```
4. Создайте репозиторий на **GitHub** (или GitLab/Bitbucket): New Repository, без README.
5. Подключите удалённый репозиторий и отправьте код (подставьте свой URL репозитория):
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/wishlist-gift.git
   git branch -M main
   git push -u origin main
   ```

**Итог:** код проекта лежит в GitHub (или другом сервисе), репозиторий доступен по ссылке.

## Шаг 2. Запустить API на вашем сервере (185.125.219.107)

Фронт на Vercel будет обращаться к вашему API. API должен работать на этом же сервере, где уже есть база данных.

### 2.1. Подключиться к серверу по SSH

На своём компьютере в терминале:

```bash
ssh -i ~/.ssh/id_ed25519_vps root@185.125.219.107
```

### 2.2. Создать папку для API и скопировать туда проект

**Вариант А — проект уже есть на сервере.**  
Если папка `/opt/wishlist-gift-v2` (или похожая) уже есть и там лежит код — переходите к п. 2.3.

**Вариант Б — копируете с компьютера.**  
На своём компьютере (в новом окне терминала, не на сервере):

```bash
cd /Users/vladislav/wishlist-gift-v2
tar --exclude='node_modules' --exclude='.git' --exclude='.env' -czf /tmp/wishlist-gift.tar.gz .
scp -i ~/.ssh/id_ed25519_vps /tmp/wishlist-gift.tar.gz root@185.125.219.107:/tmp/
```

Потом снова на сервере (по SSH):

```bash
mkdir -p /opt/wishlist-gift-v2
cd /opt/wishlist-gift-v2
tar -xzf /tmp/wishlist-gift.tar.gz
```

### 2.3. Создать файл .env на сервере

На сервере выполните:

```bash
cd /opt/wishlist-gift-v2
nano .env
```

Вставьте в файл (подставьте пароль из вашего **DB_CREDENTIALS.txt** вместо `ПАРОЛЬ_ИЗ_ФАЙЛА`):

```env
NODE_ENV=production
PORT=3000

DB_HOST=127.0.0.1
DB_PORT=5432
DB_NAME=wishlist_gift
DB_USER=wishlist_gift
DB_PASSWORD=ПАРОЛЬ_ИЗ_ФАЙЛА

BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
JWT_SECRET=любая_длинная_случайная_строка_для_подписи_токенов
APP_URL=https://ваш-проект.vercel.app
CORS_ORIGIN=*
```

Сохраните: `Ctrl+O`, Enter, `Ctrl+X`.

- **BOT_TOKEN** — токен бота для Wishlist Gift от @BotFather.
- **JWT_SECRET** — придумайте длинную случайную строку (например: `openssl rand -base64 32`).
- **APP_URL** — пока можно поставить заглушку `https://wishlist-gift.vercel.app`; после деплоя на Vercel замените на реальный адрес сайта.
- **CORS_ORIGIN** — `*` разрешает запросы с любого домена (в т.ч. с Vercel). Позже можно заменить на точный домен Vercel.

### 2.4. Установить зависимости и запустить API

На сервере:

```bash
cd /opt/wishlist-gift-v2
npm install
pm2 start server/index.js --name wishlist-api
pm2 save
pm2 status
```

В списке должен появиться процесс **wishlist-api** со статусом **online**.

### 2.5. Открыть порт 3000 (если с вашего компьютера API не открывается)

Если к серверу обращаются по интернету, на сервере часто нужно разрешить порт. Пример для ufw:

```bash
ufw allow 3000
ufw status
```

(Или настройте порт в панели хостинга / файрвола.)

**Итог:** API работает на сервере по адресу `http://185.125.219.107:3000`. Проверка в браузере: `http://185.125.219.107:3000/api/config` — должен вернуться JSON.

## Шаг 3. Подключить проект к Vercel и задеплоить фронт

1. Зайдите на сайт **https://vercel.com** и войдите (через GitHub удобнее).
2. Нажмите **Add New** → **Project**.
3. Выберите репозиторий с проектом Wishlist Gift (из шага 1). Если репозитория нет в списке — настройте интеграцию Vercel с GitHub.
4. В настройках проекта:
   - **Root Directory:** если весь репозиторий — один проект `wishlist-gift-v2`, укажите `wishlist-gift-v2`. Если в репозитории только этот проект без подпапки — оставьте пустым.
   - **Framework Preset:** **Other** (или **None**).
   - **Build Command:** оставьте как есть (должно подхватиться `npm run build` из `vercel.json`).
   - **Output Directory:** оставьте как есть (должно подхватиться `public` из `vercel.json`).
5. Важно — перед первым деплоем добавьте переменную окружения:
   - Раскройте **Environment Variables**.
   - **Name:** `API_URL`
   - **Value:** `http://185.125.219.107:3000/api`  
     (это адрес вашего API **с путём /api** в конце; если позже сделаете домен для API — замените на него, например `https://api.ваш-сайт.ru/api`).
   - Выберите **Production** (и при желании **Preview**).
   - Нажмите **Add**.
6. Нажмите **Deploy**.

Дождитесь окончания сборки. В конце будет ссылка вида **https://ваш-проект.vercel.app**.

**Итог:** фронт открывается по этой ссылке и при запросах к API использует `http://185.125.219.107:3000/api`.

## Шаг 4. Подставить в .env на сервере реальный URL Vercel (и при желании CORS)

1. Скопируйте точный адрес вашего сайта на Vercel (например `https://wishlist-gift.vercel.app`).
2. На сервере откройте `.env`:
   ```bash
   ssh -i ~/.ssh/id_ed25519_vps root@185.125.219.107
   cd /opt/wishlist-gift-v2
   nano .env
   ```
3. Замените строки:
   - `APP_URL=https://ваш-проект.vercel.app` → подставьте ваш реальный URL Vercel.
   - При желании замените `CORS_ORIGIN=*` на `CORS_ORIGIN=https://ваш-проект.vercel.app` (без слэша в конце).
4. Сохраните файл и перезапустите API:
   ```bash
   pm2 restart wishlist-api
   ```

**Итог:** бэкенд знает, с какого домена к нему ходят, и при необходимости CORS ограничен только вашим фронтом.

## Шаг 5. Проверить, что всё работает

1. Откройте в браузере сайт на Vercel (ссылку из шага 3).
2. Должна открыться главная страница Wishlist Gift.
3. Перейдите, например, в раздел «Кабинет» или «Вишлист» — страницы не должны падать с ошибкой сети. Если видите ошибки в консоли (F12 → Console) про «failed to fetch» или CORS — проверьте:
   - что на Vercel в переменных задан **API_URL** и после добавления переменной был сделан **Redeploy**;
   - что на сервере API запущен: `pm2 status`, процесс **wishlist-api** — **online**;
   - что по адресу `http://185.125.219.107:3000/api/config` в браузере возвращается JSON.

**Итог:** фронт на Vercel открывается и успешно общается с API на вашем сервере.
