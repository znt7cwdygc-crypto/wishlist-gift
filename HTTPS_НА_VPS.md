# HTTPS на VPS по IP (185.125.219.107:3000)

Чтобы открывать сайт как **https://185.125.219.107:3000**, на сервере нужен SSL-сертификат. Для доступа по IP используется **самоподписанный** сертификат (браузер покажет предупреждение — его можно принять и продолжить).

---

## Шаг 1. Подключиться к серверу

```bash
ssh -i ~/.ssh/id_ed25519_vps root@185.125.219.107
```

---

## Шаг 2. Создать папку ssl и сертификат

На сервере (в папке проекта):

```bash
cd /opt/wishlist-gift-v2
mkdir -p ssl
openssl req -x509 -newkey rsa:2048 -keyout ssl/key.pem -out ssl/cert.pem -days 365 -nodes -subj "/CN=185.125.219.107"
chmod 600 ssl/key.pem
chmod 644 ssl/cert.pem
```

Либо запустить скрипт из репозитория (если он уже залит):

```bash
cd /opt/wishlist-gift-v2
bash scripts/create-ssl-cert.sh 185.125.219.107
```

---

## Шаг 3. Обновить .env

В `.env` на сервере должен быть **https** в APP_URL:

```bash
nano /opt/wishlist-gift-v2/.env
```

Измените строку APP_URL на:

```env
APP_URL=https://185.125.219.107:3000
```

Сохраните (Ctrl+O, Enter, Ctrl+X).

---

## Шаг 4. Перезапустить приложение

```bash
pm2 restart wishlist-api
pm2 logs wishlist-api --lines 5
```

В логах должно быть: `🚀 Server running at https://0.0.0.0:3000` и при наличии BOT_TOKEN — `✅ Telegram webhook set: https://185.125.219.107:3000/api/payments/telegram-webhook`.

---

## Шаг 5. Открыть в браузере

Перейдите по адресу: **https://185.125.219.107:3000**

Браузер покажет предупреждение о самоподписанном сертификате (например «Ваше подключение не защищено» или «Небезопасно»). Нажмите «Дополнительно» → «Перейти на сайт» (или аналогичную кнопку). После этого сайт откроется по HTTPS.

---

## Важно

- **Telegram webhook**: после перехода на HTTPS в `.env` должен быть `APP_URL=https://185.125.219.107:3000`. При перезапуске сервер сам вызовет setWebhook с этим URL — Telegram принимает HTTPS по IP.
- **Порт 3000**: если файрвол блокирует, откройте: `ufw allow 3000 && ufw status` (при активном ufw).
- Для **нормального доверенного сертификата** (без предупреждения в браузере) нужен домен и, например, Let's Encrypt. По одному IP только самоподписанный сертификат.
